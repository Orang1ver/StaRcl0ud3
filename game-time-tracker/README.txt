游戏时长统计工具(仅本机,Windows)
====================================

统计规则:
只要 games.txt 里填写的游戏进程在运行,就累计时间。
游戏最小化、挂后台、人离开不操作,都照常计时。

怎么用:

【自动后台运行(推荐)】
1. 双击 install-autostart.bat。
2. 如果弹出"用户账户控制",点"是"(需要管理员权限来创建计划任务)。
3. 脚本会创建计划任务并立即后台启动,之后每次登录自动运行。
4. 改 games.txt 不用重启,几秒内自动生效。
5. 看统计:双击 show-report.bat。
6. 想停止自动记录:双击 uninstall-autostart.bat(也会弹 UAC);
   只想停当前这次:双击 stop-autostart.bat。

【每次手动开(备选)】
1. 双击 start-tracker.bat 开始记录,黑窗口最小化。
2. 结束后切到黑窗口按 Q 停止。

注意:
- 装了自动后台运行后,不要同时双击 start-tracker.bat,
  脚本会提示 already running,这是防重复保护,属正常现象。
- 自动模式每 60 秒存一次数据,直接关机/注销最多丢最后 1 分钟。
- 脚本纯本地运行:只读取本机进程列表并向 activity.csv 写入时间,
  不联网、不修改其他文件。全部内容都可以用记事本打开查看。
- 如果杀毒软件拦截了本工具(脚本自动启动常被误报),可以在
  卡巴斯基的"排除项/信任区域"里添加整个 game-time-tracker 文件夹;
  被隔离的文件请先从隔离区恢复。
- 进程名查看:游戏运行时按 Ctrl+Shift+Esc,任务管理器"详细信息"
  页里找到游戏进程,例如 cs2.exe 就填 cs2,不要带 .exe。
- 数据文件 activity.csv 可随时删除,删除即清空历史。
- 如果同时填了启动器和游戏本体,时间可能被重复计算,建议只填游戏本体。
